Customer Shopping Behavior - End-to-End Data Analytics ProjectAn end-to-end data analytics project analyzing customer purchasing patterns, demographics, and transactional habits. This project covers the full data lifecycle: data loading, exploratory data analysis (EDA), data cleaning, feature engineering, SQL-based business intelligence querying, Power BI dashboarding, executive reporting, and presentation design.📌 OverviewUnderstanding customer behavior is critical for retail optimization, targeted marketing, and inventory management. This project ingests raw customer shopping data, cleans and transforms it using Python, loads it into a relational database for advanced SQL analysis, and visualizes key metrics through an interactive Power BI dashboard and an executive presentation.📂 DatasetSource File: customer_shopping_behavior.csv   Records: 3,900 rows   Attributes: 18 columns covering customer demographics (Age, Gender, Location), purchase details (Item Purchased, Category, Purchase Amount (USD), Size, Color, Season), and transactional behavior (Review Rating, Subscription Status, Shipping Type, Discount Applied, Previous Purchases, Payment Method, Frequency of Purchases).   🛠️ Tools & Tech StackPython (Pandas, SQLAlchemy): Data ingestion, exploratory data analysis (EDA), cleaning, feature engineering, and automated database loading.PostgreSQL: Relational database management and complex analytical querying (SQL).Power BI: Interactive dashboard and visual report building.Gamma: Executive presentation and slide generation.🚀 Project Steps & Workflow1. Exploratory Data Analysis & Data Cleaning (Python)Null Value Treatment: Identified 37 missing values in Review Rating and filled them using the median review rating grouped by product Category.Standardization: Converted column headers to lowercase and replaced spaces with underscores (e.g., purchase_amount_(usd) $\rightarrow$ purchase_amount_usd).Feature Engineering:Created an age_group column (Young Adult, Adult, Middle Aged, Senior) using quartile bucketing (pd.qcut).Mapped text-based purchase frequencies to numerical purchase_frequency_days (e.g., Weekly $\rightarrow$ 7 days, Monthly $\rightarrow$ 30 days).Dropped redundant columns (promo_code_used).2. Database Integration & SQL AnalysisThe cleaned dataset was loaded into a PostgreSQL database (customer_behavior) using SQLAlchemy. A series of 10 business intelligence queries were executed to extract deep insights:   Revenue Breakdown: Evaluated total revenue generated by male vs. female customers.   Discount Impact: Identified customers who used discounts yet spent above the average purchase amount.   Product Quality: Determined the top 5 products with the highest average review ratings.   Shipping Analysis: Compared average purchase amounts between Standard and Express shipping.   Subscription Value: Analyzed spending behavior between subscribers and non-subscribers.   Customer Segmentation: Segmented customers into New, Returning, and Loyal tiers based on their past purchase history.   Category Rankings: Extracted the top 3 most purchased products in each category using window functions (ROW_NUMBER()).   Demographics: Analyzed which age groups contribute most significantly to total revenue.   3. Dashboard & ReportingPower BI Dashboard: Developed an interactive reporting suite utilizing a structured model schema to visualize customer segments, regional trends, category performance, and discount utilization.Presentation: Compiled key findings and strategic recommendations into a slide deck using Gamma.📊 Key Results & InsightsDemographics & Revenue: Middle-aged and adult segments drive the largest share of overall transaction volume and total revenue.Subscribers vs. Non-Subscribers: Subscribers demonstrate consistent purchasing patterns, representing a high-value customer segment.Product Performance: Certain product categories rely heavily on discount applications to drive volume, highlighting opportunities for pricing strategy optimization.⚙️ How to Run LocallyClone the Repository:Bashgit clone https://github.com/your-username/customer-shopping-behavior-analytics.git
